# Учебная папка

Здесь хранится всё, что вы получаете и делаете на курсе. Откройте эту папку в своём агенте.

- `transcripts/` — транскрипты занятий. Кладёте сюда сами.
- `notes/` — конспекты и заметки: Markdown, HTML-страницы и другие файлы, которые агент делает по вашей просьбе.
- `.agents/skills/` — скиллы курса. Появятся на следующих уроках.

После первого урока положите транскрипт занятия в `transcripts/` и попросите агента сделать конспект.
